# Hi, I'm Alp

I'm a back-end development student at Noroff, currently in my second year. I build REST APIs with Node.js and Express, and I'm now working with Docker, CI and cloud deployment on Azure.

## What I work with

- **Back end:** Node.js, Express, Sequelize, MySQL, MongoDB, Mongoose
- **Auth and API docs:** JWT, Passport, Swagger
- **Testing:** Jest, Supertest
- **Front end:** HTML, CSS, JavaScript, React, TypeScript, Tailwind CSS, Bootstrap, EJS
- **Deployment:** Docker, GitHub Actions, Azure
